# Roundo font source

Roundo by Indian Type Foundry, distributed through Fontshare.
Source: https://www.fontshare.com/fonts/roundo
Fontshare licensing: https://www.fontshare.com/licenses

The locally served WOFF2 files are the original Fontshare 400, 500 and 600 webfont files, downloaded through the public Fontshare CSS endpoint. No font modifications were made.
