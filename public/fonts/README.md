# MoodlIA Website Fonts

Local Roundo webfonts used by the MoodlIA website.

## Status

Roundo by Indian Type Foundry, distributed through Fontshare. The local WOFF2 files are the original 400, 500 and 600 webfont files downloaded through the public Fontshare CSS endpoint. No font modifications were made.

## Usage

Serve these files locally through the website build. Retain their provenance and applicable font terms when redistributing the website.
