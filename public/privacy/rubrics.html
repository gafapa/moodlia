MoodlIA Rubrics privacy policy

Also published as Rubricando for Moodle. This page preserves the existing extension policy in English. Imported from the Rubrics project on 20 October 2026.

This Privacy Policy explains how Rubricando for Moodle handles data when users import Moodle rubrics from CSV/Excel files and, where available, use AI-assisted features.

Who we are

Rubricando for Moodle is a Chrome extension designed to help import criteria, level descriptions and scores into Moodle rubric editing pages from CSV/Excel files.

What data the extension handles

The extension may handle the following categories of data:

  • CSV/Excel files explicitly selected or dropped by the user.
  • Rubric-related content already present on compatible Moodle rubric editing pages.
  • User actions required to perform the import, such as selecting a file or starting it.
  • Technical request data needed to complete optional calls to remote AI APIs, if those features are enabled.

How the extension uses data

  • To interpret CSV/Excel content and extract criteria, levels and scores.
  • To insert the import interface into compatible Moodle rubric editing pages.
  • To complete the Moodle rubric form with the data provided by the user.
  • To support optional AI-assisted features, if they exist and the user uses them.

AI processing

The extension may include AI-assisted features in some versions. When those features are available, data may be processed in one of these two ways, depending on the feature and configuration:

  • Locally on the user's device through a local model.
  • Remotely through an external AI API provider used to complete the requested feature.

When remote AI processing is used, only the content reasonably necessary to run the feature requested by the user should be transmitted. This may include parts of the selected CSV/Excel file, rubric text on the Moodle page and user prompts or instructions. If a remote provider is used, that provider may handle the submitted data according to its own terms and privacy policy.

Data sharing

We do not sell user data. We do not share user data with third parties except in these cases:

  • When the user explicitly uses an AI-assisted feature that depends on a remote API provider.
  • When disclosure is required by law, regulation or legal process.
  • When sharing information is technically necessary to provide the requested feature through network infrastructure.

Remote code

The extension does not download or execute remote JavaScript or WebAssembly code as part of its main operation.

Data retention

The extension is designed to process imports locally in the browser whenever possible. We do not operate a backend database to store imported rubric files or Moodle page content. If an optional remote AI API is used, transmitted data may be retained by the relevant provider according to its own policy.

Security

We aim to minimize data access to what is strictly necessary for the extension's single purpose. When requests to remote APIs exist, they should be transmitted through secure channels such as HTTPS.

User choices

  • Users choose which CSV/Excel file to import.
  • Users can stop using the extension at any time by uninstalling it.
  • Users can avoid remote AI processing by not using AI-assisted features that depend on external APIs.

Changes to this policy

This Privacy Policy may be updated when the extension changes, including if new AI-assisted features or integrations are introduced. The latest published version of this page is the applicable version.

Contact

For privacy or support questions, use the contact or support URL listed in the Chrome Web Store listing for Rubricando for Moodle.
